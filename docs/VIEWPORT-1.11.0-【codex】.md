# 一屏游戏与大厅更新日志 · 1.11.0

日期：2026-10-24；规则：1.2.0。

## 本次实现

大厅新增更新日志，显示版本号、日期及玩家可感知的新功能。整个应用固定在浏览器可见窗口内，3D 牌桌随可用宽高等比缩放；小屏和横屏压紧工具栏，座位名单、评审、更新日志与菜单在自身面板内滚动。保留独立底部版本号，窗口变化不改变牌局或提交命令。应用 1.11.0，规则仍 1.2.0。

- 大厅右上角“更新”打开更新日志，列出版本、发布日期和简短功能。弹窗标题/关闭入口保持可见，长记录内部滚动。
- 固定游戏根容器读取 visualViewport；桌面、竖屏、短横屏分别使用紧凑布局。3D 牌桌保持比例，主要按钮留在窗口内；手牌、座位名单与评审内容具有独立边界。
- 软键盘可见区域变化接入 resize/scroll 监听；本次未进行实体设备软键盘验收。
- CSS 在独立 game-viewport.css 中集中定义；既有命令、胡牌确认和权威游戏规则不变。
