# 1.7.0 管理员与字库交付

应用1.7.0已发布，规则继续1.2.0。右上角管理入口使用用户指定密码，独立管理员会话不替换玩家身份。大厅显示逐座昵称与AI标记，管理员可直接踢人；候场/结算释放座位，活动局由新AI接手原牌，旧会话与恢复码失效。管理员可解散公共或邀请房；有指定AI且无在线真人连续120秒自动正式关闭，重连取消。字库可查看、查找、增删改汉字及2–6人配比，保存从下一局生效，当前牌墙不变。

## 使用

1. 大厅或牌桌右上角点击“管理”，输入用户指定密码登录。
2. 关闭面板仍保留管理模式；大厅每个真人昵称旁显示“踢出”，点击后在游戏内确认。正在游戏的玩家由AI接手，旧身份与恢复码立即失效；它不是永久封禁。
3. 管理面板列出所有未关闭房间，包括邀请房。可逐人踢出或解散整房；活动AI不单独移除，可解散整房。牌局版本发生变化会拒绝旧操作，应取消确认、刷新后重新选择。
4. “麻将字库”可查找、添加、改字、改每个人数的数量、删除，再保存；退出前提醒未保存修改。保存从下一局发牌生效。
5. “退出管理”撤销管理员会话；玩家身份不受影响。

## 权威行为

- 管理密码只在服务端用scrypt校验；生产8小时HttpOnly/Secure/SameSite=Lax会话，独立Cookie路径，写操作检查Origin、登录限流，凭据不提交Git。配置工具见ops/README.md。
- 解散、踢人、撤会话及审计在SQLite事务中落盘后广播；并发旧状态拒绝。解散保留历史，当前局不计分。冻结评审保留已有票或弃权，不凭空给接手AI增加一票。
- 含指定AI且无在线真人满120秒关闭，截止时间持久化，重连取消，重启不延期。候场/结算15秒释放公共桌是旧规则，不能误报为房间已解散；纯真人房继续24小时策略。
- 字库修订并发校验；1–500个不同汉字，每字每人数0–20张，每人数总数13N+21至1000。新局冻结全配置，旧局墙/手牌/存档不变。3D匿名牌墙最多绘制216张，中央剩余数量仍准确。
