# 六张固定公共桌 · 1.2.0

用户明确要求所有人看到相同占用状态并点击入座。大厅为固定01—06号桌；空桌创建2—6人房间，已有桌显示人数（含AI）和等待/对局中/结算状态。已有桌直接查询空座，同浏览器自己的桌可原身份恢复；进行中不新增玩家。创建弹窗明确其他玩家可以直接入座。旧私房不自动放入公共大厅。

## 共享与恢复

`GET /api/lobby`只公开六项桌号、房间码、容量、占用数、阶段，不公开姓名、手牌、投票或凭据。页面每2秒同步、切回前台立即同步，后台降低轮询；断网时暂停大厅操作并提示重连。

`POST /api/rooms`的tableNumber可选；公共UI必传1—6，旧私房API不变。绑定与创建/身份/事件在同一SQLite事务；非法400、竞争409，没有失败后孤儿房或空占桌。只有创建可绑定桌号。

关房立即释放桌号。候场/结算无在线真人时给15秒缓冲，及时恢复取消释放；持久期限重启不顺延。到期仅解除公共映射，原房/身份仍按原24小时规则保留，旧恢复不会占回已释放的公共桌。对局中全离线沿用原24小时暂停规则，防止丢失进行中牌局。
