# 手牌交互 · 1.3.0

## 用户需求与语义

追加要求：UI和按钮应像游戏，减少铺开的网页说明。大厅六桌采用木边绿绒缩略牌桌、座位圆点与金色入场按钮；玩法和恢复入口收进图标工具。牌桌采用紧凑状态栏、主要游戏动作及折叠工具面板。


拖动汉字牌时抬起并浮在其他牌上方，目标插入位置留出空隙，相邻牌让位，松手后落下。逗号是独立透明牌，视觉宽度为半张汉字牌，不再画在汉字牌上。

普通草稿、借字候选及胡牌句子的逗号仍使用左侧实体tileId锚点；不新增实体麻将牌，不计入14字和圈词索引。最多三个，不能放末尾。整理不等于出牌，出牌仍须确认。

## 验收范围

| 检查 | 预期 |
|---|---|
| 桌面3D拖字 | 抬起跟手、相邻让位、放手顺序正确；牌数和实体ID不变 |
| DOM整理拖字 | 与3D共享同一顺序，取消保留原草稿 |
| 独立逗号 | 半宽透明，有实际布局空间；可移动、收回 |
| 保存恢复 | 新牌序与逗号锚点经过真实服务保存后恢复一致 |
| 同步与失焦 | 阶段、身份、牌权等变化时清理拖动；不回滚权威数据 |
| 手机与辅助操作 | 按宽度换行，保留键盘、左右移和放/收逗号；尊重减少动态偏好 |
