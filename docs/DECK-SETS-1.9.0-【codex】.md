# 麻将套组 · 1.9.0

## 使用

右上角「管理」→ 输入既有管理员密码 →「麻将字库」。选择一个套组，在「新套组名称」中命名，再点「复制当前 · 新建套组」。新组会复制当前已保存的字库，随后可改名称、增删汉字、修改2–6人桌的各字张数，点「保存套组」。点「设为默认套组」指定以后开房默认选择。

玩家在大厅点空桌或「创建房间」，可从「麻将套组」下拉框选择；初始自动选中当前默认套组，并显示汉字种类与所选人数的总牌数。候场座位区和牌桌工具面板可查看房间套组。

## 生效与保护

- 旧单一字库迁移为「经典字库」，完整保留原修订、字牌与历史。
- 房间创建时绑定套组ID。切换全局默认，不改已有房间；绑定不随改名改变。
- 开始每局读取所绑定套组的最新修订；本局完整字库、名称、版本与牌墙冻结。下局使用编辑后的内容，旧局归档保留原名称。
- 名称1–30字符、不能重名；最多50套组，每组1–500种汉字，每字各人数配比0–20张。各人数总牌数必须满足发牌与余牌下限，上限1000张。
- 当前不提供删除套组，避免断开已有房间绑定。旧组可保留，玩家开房选择新组。
- 编辑未保存时禁止切换套组、设默认或复制，关闭会提示放弃；管理员登录失效后重新登录可继续未保存编辑。刷新整个网页仍会失去未保存编辑。
- 服务端管理员认证、同源检查、独立修订CAS、目录CAS、事务审计与创建幂等；不会因重试创建重复组。创建/保存已成功但目录刷新失败会明确提示并暂停新建/设默认，刷新后继续。

## 实现

共享类型在 `packages/contracts/deck.ts`；存储 `apps/server/deck-sets.ts`；管理编辑器 `apps/web/src/DeckSetEditor.tsx`；开房选组 `OnlineApp.tsx`。公开GET `/api/deck-sets`仅返回目录摘要；管理员GET/POST `/api/admin/deck-sets`、GET/POST `/api/admin/deck-sets/:id`及POST `/api/admin/deck-sets/default`管理配置。创建房间POST `/api/rooms`可传`deckSetId`，旧客户端不传则使用创建时的默认组。

SQLite新增 deck_sets、deck_set_revisions、deck_catalog、deck_set_receipts、room_deck_sets；经典组继续镜像原 deck_revisions/deck_current。整库备份包含全部组及历史。schema_info与快照codec仍1，代表可加式迁移，不代表允许降级：含新套组的存档必须使用兼容1.9的构建恢复，不能交给旧构建继续写库。
