# 胡牌评审弹窗 · 应用 1.12.0 / 规则 1.3.0

日期：2026-10-24。

## 实现

应用 1.12.0 将胡牌逐字亮相、圈词投票和结果整合到约占可见窗口 80% 宽高的游戏弹窗。新规则 1.3.0 评审限时 60 秒，牌下实名显示各评审考虑中/赞成/反对/未投；反对票可点选最多三段字词，提交后向全桌广播，并从对应投票卡片向异议字牌扔出鸡蛋、留下蛋液标记。通过与未通过分别盖章庆祝/震动落印。

倒计时来自服务器 deadline，冻结评审全部投票后可提前结算；未投到期计弃权，严格过半不变。断线暂停沿用既有规则。圈选由逐字点击切换，相邻字合并，允许反对不选词；AI 仍独立70%赞成，不生成圈词。

未提交的圈选仅本机预览；已提交的真实票/圈词与昵称广播给同桌。结果保存公开名单；管理员踢人后仍保留原冻结评审身份，不由新 AI 代投。公开内容不含暗牌、恢复码或随机状态。新字段读写与命令回执同事务，重复动作不重复投票/抽票。

亮相和评审统一在80%宽高弹窗内，背景仍可看到牌桌。窄屏牌面7+7，短横屏14字一排，名单内部滚动；可跳过亮相立即投票。减少动态效果下保留票意、颜色、蛋液静态标记与结果，停止飞行/震动。resize/面板滚动清除不再对应牌位的飞蛋。旧版 HuShowcase 保留为来源，生产入口已改用 HuReviewDialog；旧 verify-hu-showcase 命令转入新评审验收脚本。
