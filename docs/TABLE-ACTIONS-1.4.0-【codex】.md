# 牌桌操作 · 1.4.0

用户要求：右侧三张可拖拽半透明半宽逗号；去掉主界面无感的保存和箭头；打、吃、胡靠近牌桌；拖到中央出牌；明显展示对手当前打出的字。

## 实现

- 三张实体感逗号按当前手牌显示尺寸取半宽，同高度；已用数量显示为空槽，可从句子拖回牌架。
- 游戏操作集中在牌桌内：选牌后打、正常局胡、响应期吃/胡/过、借字提交。练习局仍按规则隐藏胡。
- 中央出牌区只在拖字时高亮；释放后进入现有确认，确认才发DISCARD。断线、无牌权、禁止立即弃回的字不会提交。桌外释放取消预览，不能因最近邻误排牌。3D与DOM整理共用此逻辑。
- 最新弃牌优先使用当前响应窗口的discardId；显示公开字、出牌者和金框；离开窗口标上张弃牌或已被吃走，避免把旧牌当可接的牌。首次出现有短放大动画，减少动态偏好时关闭。
- 自动保存保留；左右微调、逗号辅助和手动同步收进工具，键盘操作保留。
