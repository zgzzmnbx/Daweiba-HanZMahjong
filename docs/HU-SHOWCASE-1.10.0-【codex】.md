# 胡牌确认与全桌亮相 · v1.10.0

应用1.10.0：自摸胡与借字排好后提交，先弹出“你确认你觉得这是一句完整的人话吗？”并预览14字；取消不提交。确认后全桌从申请人实际牌位逐字飞入、放大砸落，配金色卡通火花、落地回弹与轻震，桌面14字一排，手机7+7。亮相约3.7秒，可提前收起继续评审；没有把申请亮相当作胡牌通过。

200项自动测试（新增5项）、TypeScript与生产构建通过。本地及公网三个独立Chrome身份完成确认/取消、自胡、借字胡、提前收起投票、结算刷新不重播和AI即时评审；1440桌面、390/430手机尺寸与减少动态效果已验。三端首次显示时间差：本地20ms，公网0ms（本次环境实测，不承诺跨地域固定延迟）。无浏览器异常。

发布 `1.10.0-20261023-134321`，发布前一致性备份 `pre-release-20261023-134322.sqlite` 通过；公网 `/readyz` 返回true。只操作自建私有验收房，测试结束关闭；原房间、套组和云端端口配置不变。规则仍1.2.0。

## 实现与边界

- GameTable在自摸DECLARE_SELF_HU、借字SUBMIT_DISCARD_SENTENCE之前使用游戏内确认dialog，保存当时句子；phase/身份/连接/暂停变更关闭确认，提交再次校验句子与权限。弃牌仍无需确认；借字响应的“胡”先保留弃牌进入排句，最终提交时才确认。
- HuShowcase消费服务端公开proposal与快照差分。可选revealedAt由引擎统一写入，评审历史/AI瞬结/持久化保留；旧快照缺字段仍兼容。首次载入、重复快照、断线恢复、旧事件、换局不重播。
- 起点来自本人实体牌槽或对手匿名手牌槽，只有已经公开的句子可进入动画。逗号跟随句序；不读取对手暗牌。原摸/打/吃飞牌沿用，原小型HU飞牌由本次全屏亮相替代。
- 14字间隔125ms，单牌430ms：飞入、放大、砸落、回弹；SVG火花与冲击圈均为程序绘制。装饰不拦截跳过按钮。modal阻止误触底牌，可跳过/按Escape收起，自动结束恢复操作；服务器评审期限不延长。
- prefers-reduced-motion直接展示静态完整句子，禁用火花/冲击/震屏；resize取消过期几何。
- 本次为真实Chrome桌面及手机尺寸模拟，非实体手机GPU/蜂窝/读屏验收。公网游戏仍依赖Mac在线唤醒。
