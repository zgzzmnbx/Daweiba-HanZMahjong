# 全桌出牌报字 · 2026-10-24

## 用户要求与行为

真正出牌成功后，全桌朗读该字。按钮出牌、拖到桌中央出牌、指定 AI 与主动托管出牌使用同一规则。点击、触摸或键盘选中自己的手牌保持安静；管理员字库试听和胡牌整句朗读继续保留。

每端只消费服务器公开快照中新增加的 `discardId`，读取已公开的字，不读取其他人的暗牌，不根据按钮点击猜测是否出牌成功。身份、房间、轮次、暂停与连接状态均参与门控，重复/旧快照与弃牌被吃走的状态变化不重念。观战端沿公开快照使用相同规则。

单字音频沿用已生成的 Qwen Cherry 中文缓存，每字 1.1 秒；快速连续的新弃牌按权威顺序逐个播放。静音、断线、隐藏、失控、离开或切换轮次会停止音源、取消迟到请求并清理队列；恢复后建立静默基线。语音与动作音效保持独立开关，朗读时沿用音效压低逻辑。观战的语音开关移入常驻声音面板，未有胡牌记录时也能操作。

各设备保留自己的语音开关。浏览器首次需要玩家点击或按键解锁声音；未解锁期间不积压报牌。没有音频素材或请求失败时显示语音未就绪，计时与游戏继续由服务器推进。

- `apps/web/src/discard-speech.ts`：仅基于公开弃牌的事件识别。
- `apps/web/src/speech-client.ts`：串行播放、取消与生命周期门控，接入全桌公共弃牌。
- `apps/web/src/GameTable.tsx`：移除 `select` 中的 `speech.playTile`；按钮与拖放命令入口保持原样。
- `apps/web/src/SpectatorTable.tsx`：观战语音开关常驻。
- 语音、音效和综合体验回归脚本按新行为调整；`tests/ui/discard-speech.test.ts` 新增四项公开事件测试。

不修改游戏协议、数据库、规则版本和服务器期限。与竖屏菜单联合发布，版本/README/CHANGELOG及正式部署由发布线程统一收口，避免两个候选覆盖上线。

`scripts/verify-discard-speech.mjs` 的 **12 项真实 Chrome 检查**通过，使用独立 SQLite、独立 Cookie 的真实三位玩家、指定 AI、主动托管和匿名观战，以及已有真实 Qwen 字牌缓存。检测真实 AudioBufferSourceNode 播放、PCM 指纹一致与输出分析器非零波形，未将接口请求成功当作已播放。

2. 按钮出牌后，三玩家及观战分别只请求、解码、播放一次正确的同字音频，时长1.1秒、PCM指纹一致。
3. 排列保存、观战重复轮询和后续快照不重播。
4. 手机真实拖动出牌，各端报字一致。
5. 单独静音与重新开启不补播。
6. 玩家刷新恢复与观战刷新静默。
7. 恢复后的第一张真实新弃牌正常播放。
8. 静音取消正在加载的真实缓存音频；迟到响应不再启动。
9. 快速连续两张弃牌按顺序完整播放，第二字至少相隔1秒启动。
10. 指定 AI 真正弃牌，两个真人和观战均只报一次。
11. 真人主动托管、controlEpoch 改变后，AI 出牌仍向各端报字。
12. 只关闭自身验收房，无计分、无新增天书条目。
