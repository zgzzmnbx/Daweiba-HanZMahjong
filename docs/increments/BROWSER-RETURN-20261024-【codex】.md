# 原浏览器找回座位 · READY · 2026-10-24

已按用户选择实现：不显示或输入恢复码；大厅点击原房间后，原浏览器可点击自己的头像接管。掉线托管显示“原名（AI托管）”，恢复后回到原名。大厅“我的座位”保留可恢复房间入口，覆盖未列在公共桌上的活动私人房。已识别身份时省去昵称/房间码输入；页面根路径保持大厅，直接房间刷新仍支持自动恢复。

## 身份与兼容

- 新增按房间路径隔离的 HttpOnly / SameSite=Lax Cookie，生产为 Secure、30天；只在事务成功后写入，数据库仅存散列。localStorage仅保存最多12个公开房间码，不存秘密或玩家ID。
- 旧房间有效SESSION可以无感补发浏览器凭据；BROWSER恢复复用现有事务、controlEpoch撤销和幂等收据。跨房间的全局会话覆盖不影响原房间凭据。
- 只有匹配房间凭据的原座位返回returnSeat；同名/伪造seat/陌生浏览器/指定AI/已踢出/关房均不能冒领。目录只公开昵称、座号、AI/托管标记，不公开ID、手牌或散列。
- 旧RECOVERY_CODE协议保留兼容历史调用，但玩家UI、弹窗、帮助、工具按钮已移除。现有15秒未开局空位释放、活动局掉线AI、120秒AI空房关闭与24小时保留规则不变；已释放/已关闭座位不列入“我的座位”。清除浏览器数据或换浏览器不承诺恢复。
- 不改主动AI托管引擎；SeatBadges/playerDisplayName兼容autoPlay名称。主动托管取消仍由玩家体验线程的SET_AUTOPLAY负责。
