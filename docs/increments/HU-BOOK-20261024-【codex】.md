# 胡牌天书 · 1.15.0

## 用户交付

大厅书本图标进入“胡牌天书”，所有访客均可浏览历史胡牌，卡片保留十四张字牌的原顺序、逗号、作者、北京时间和套组。练习局单独标记；未通过、撤回申请不收录。手机按七字两行展示，长列表在弹窗内部翻页。没有历史时显示空书状态，不伪造示例。

每个浏览器身份每天在全部天书句子中合计只能点赞一次，不可撤销。北京时间零点重置。不同房间与刷新共用身份；HttpOnly Cookie 保存一年，服务端保存哈希。没有统一用户账号，清除 Cookie、无痕或换浏览器视为新身份，不能宣称跨设备或防刷的实名每日限额。

管理员登录后，在大厅打开天书即可移除句子；二次确认，所有人刷新后不再看到。仅删除天书展示，对局成绩和管理员原始历史记录保留。删除不返还当日点赞额度。

## 实现

- `apps/server/hu-book.ts`：公开投影、持久读者身份、按中国时区的每日额度、删除审计；`packages/contracts/hu-book.ts` 为公开接口。
- 数据表 `hu_book` 唯一键 `(room_id,round_id,proposal_id)`；`hu_book_likes` 唯一键 `(reader_hash,day)`。点赞与数量在 `BEGIN IMMEDIATE` 内共同提交，相同句子重复请求不重复计数。
- `Store.commit` 在游戏事务内从冻结的 `admin_round_records` 捕获获批句子，任何后续存储错误一起回滚。启动时补录现有管理员历史；未知历史时间仍为空，界面明确说明未留存。
- 删除使用 `deleted_at` 墓碑和管理员审计，后续快照、重启补录不能复活。已删除句子的点赞记录保留以约束当日额度。
- `GET /api/hu-book?before=…` 每页十二句，返回总数、下一页游标、当天点赞与服务器截止时间；浏览公开，不返回房间号、玩家 ID、实体牌 ID 或凭据。
- `POST /api/hu-book/:id/like` 要求服务端已签发且持久化的浏览器身份；服务端时钟决定日期，不信任客户端参数。跨来源 POST 拒绝、接口限流。
- `POST /api/admin/hu-book/:id/delete` 每次验证管理员会话；删除重复调用幂等。
- `HuBook.tsx` / `hu-book.css`：绿绒书页、奶白字牌、点赞动效、嵌套原生 dialog 删除确认与焦点约束、减弱动态支持、内部滚动、错误与刷新入口。打开后无隐藏轮询，主动刷新可查看最新赞数与删除结果。
