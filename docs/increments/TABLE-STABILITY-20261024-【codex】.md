# 牌桌尺寸稳定性修复 · 2026-10-24

本增量随应用 1.15.0 联合发布，规则保持 1.4.0。独立复验基线为 `366405c`，仅加入下列布局与浏览器脚本；临时候选目录中的 1.14.1 是验证标识，未作为独立版本上线。

## 问题与修复

真实 Chrome 连续摸打复现：提交中的“重试提交”按钮将底部状态栏撑高 26px，1440×900 下牌桌宽度在 967.5–1006.5px 之间切换。手机的手牌行数、当前牌数和临时通知也会改变剩余高度；`overflow:hidden` 容器仍可因聚焦被程序滚动，桌面随之移动。

- 固定标题、通知区和提交状态栏高度；多条通知及较长状态只在对应区域内滚动。
- 按完整 14 字和 3 个逗号预算牌宽，DOM 手牌保留固定一至两行空间，额外行在牌架内部滚动。观察主区域的可用宽度，不依赖候场时尚未挂载的手牌节点，覆盖手机首次进房。
- 桌面端因借字/胡牌而自动显示的 DOM 排句以覆盖层承载，不挤压 3D 区域；手机评审期间保留牌架空间。同一窗口下提交、摸打、评审和提示不重建画布。
- 不允许滚动的应用、主区域和桌面容器使用 `overflow:clip`，防止焦点自动平移；短屏将操作停靠在边界内，极小竖屏的画笔、出牌和逗号分开占位，最新弃牌使用紧凑展示。

真实窗口调整和玩家主动展开/收起整理仍可重新布局。发牌、字库、计时、动画权威与身份控制不变。
