# 1.20.0 · 出牌固定二字词

用户确定每张字牌预先配一个以该字开头的二字词，生成一次、持久保存；出牌只播放缓存。胡牌继续朗读服务器已公开的完整原句。

- 当前两个套组合计178种字全部配词，见`【牌库】/出牌朗读词表-v1.0-【codex】.md`；相同字的多张牌共用同一份音频。
- 词语采用真实Qwen3-TTS-Flash/Cherry合成，去外部静音、统一响度，保留自然语速。词语profile与旧单字缓存隔离；原胡句profile/key保留。
- 按钮、真实触摸拖放、指定AI、真人主动托管、观战均消费同轮新增公开discardId，不新增命令、不改变期限。手牌点选不朗读，个人静音与恢复静默保留。
- 公共音频GET只读文件，缺失404；既有文件可在移除模型凭据后播放。仅管理员主动补全、部署预生成脚本及公开胡句按需生成可以调用语音模型。
- 管理端显示对应词并可试听；未来新增未配词汉字明确显示“待配词”，不能单字回退。变更词表须更新tile profile，避免immutable URL播放旧音。
- 不改规则1.5.1，不改牌库张数/配比/本局冻结数据，不将密钥或私有缓存提交Git。
