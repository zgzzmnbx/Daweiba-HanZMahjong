# 游戏音效 · 1.16.0

## 玩家体验

九类独立合成声音：开局鼓点与和弦、摸牌轻摩擦、出牌木牌脆响、吃牌双击、胡牌风声/低鼓/锣鸣及十四张冲击声、赞成轻铃、反对票卡通投掷与蛋碎、通过的上行庆祝和未通过的下行短音。无背景音乐循环，不新增网络音频服务、素材许可或付费调用。

牌桌“工具 → 声音”可独立开关、调音量和试听；默认55%，音量为零不创建事件声音。评审窗口可直接切换音效，观战右上角也有声音菜单。偏好在同一浏览器保存，与原有字牌/胡句语音分别控制；朗读时音效主增益压至原值30%，结束后平滑恢复。首次需要真实点击/按键后由浏览器解锁音频，不缓存此前音效等待解锁。

## 接线与约束

- `audio/sound-events.ts`：只读取公开权威快照和当前控制身份；初始/重复/逆序/断线/恢复/暂停/关闭与身份变更均不补播。长时间思考不会使合法的新出牌被误判为过时。
- 原子AI亮牌并结算时，从最新公开历史识别新胡句，先逐张落牌，再播放结果；同一批最多三段反对声。声音完全不影响游戏命令、计时和状态版本。
- `audio/synth.ts`：Web Audio 振荡器、确定性噪声、滤波与衰减包络合成。胡牌冲击时间共用亮相常量，蛋碎对齐投掷480ms落点。源结束后断开音频节点。
- `audio/use-game-sfx.ts`：用户手势解锁、独立增益、动态压缩、有限并发与短时去重。静音/零音量/失控/离线/隐藏页面立即停止，返回页面从新快照建立基线；卸载关闭AudioContext。跳过亮相或窗口变化取消未完成的胡牌落字声。
- `GameTable` 和只读 `SpectatorTable` 使用相同公开事件逻辑，不接触其他人私密手牌；评审快速开关在 `HuReviewDialog`。
- 声音无外部素材；试听文件为同一程序的离线渲染导出，游戏运行时直接合成，不下载试听文件。

## 验证

- 全量280项自动测试通过，含5项音效状态差分测试：首包、重复、控制权变化、长思考后出牌、摸吃、亮牌、终票、AI瞬结、历史不重播及多人反对上限。
- 真实Chromium OfflineAudioContext渲染九类音效，每类波形非零、峰值低于1，无数字削波。55%设置最大峰值约0.372；满音量八路同时叠加峰值约0.885；结果 `sound-render-1.16.0.json`。
- 本地14项Chrome/HTTP/Socket.IO/SQLite联机检查通过，真实AudioContext和输出分析器覆盖开局、摸打、双方音效、静音与零音量、刷新保存、14次胡牌冲击、反对与失败、通过结算、重复不响、手机控件与退出释放。语音压低使用明确标记的本地音频夹具，不冒充云TTS调用。
- `scripts/verify-sound-effects.mjs` 公网模式仅用自身两人私房、拒绝评审和无计分结束，不污染天书；不以本地结果代替公网验收。
- `scripts/verify-sound-render.mjs` 可重新生成27秒的九类声音试听；正式文件 `docs/evidence/sound-effects-1.16.0-preview.mp3`，原始PCM在Codex-Temp。
- 实体扬声器/耳机听感、Safari/iOS静音键及实体手机环境未在本次实测，不声称完成主观听音或设备全覆盖。
