# 1.8.0 摸打吃胡移动轨迹

应用1.8.0已发布，增加真实快照驱动的摸、打、吃、借胡与公开胡牌飞行轨迹。摸牌从可见匿名牌墙末端飞入手牌右侧；本人出牌从当前实体牌槽飞向对应弃牌位，对手从其座位手牌槽飞出；吃/借字从对应弃牌位到本人牌列。胡牌14字依次飞到桌面7+7公开句区，AI即时评审也显示。桌面3D投影与DOM整理手牌共享效果；不改变规则1.2.0、命令或计时。

## 表现与位置

| 动作 | 起点 | 落点 |
|---|---|---|
| 本人摸牌 | 当前可见匿名墙末端 | 新牌右端实体槽，落地后保留高亮 |
| 对手摸牌 | 当前可见匿名墙末端 | 对应座位匿名手牌槽，始终牌背 |
| 打牌 | 本人准确牌槽或对手对应座位的匿名槽 | 此实体弃牌在中央弃牌区的位置 |
| 吃、借胡 | 对应discardId的当前弃牌位 | 本人右端/候选引用槽 |
| 胡牌提交 | 申请者手牌槽；借牌沿引用位 | 14张公开字牌在桌面7+7句区 |

MainView直接投影实际几何边界，DOM整理用当前元素rect；保存前一帧位置以支持牌已从权威手牌移出后的飞行。对手暗牌排序不可见，因此出牌以对应座位匿名手牌末端作为表现位置，不新增或猜测暗牌身份。墙块同样是匿名显示，不透露未来发牌内容。

飞牌层不拦截点击，不控制规则。重复快照、本地排句不重播；换身份、换局、断线恢复、暂停/关房、滚动与resize清理旧轨迹。AI合并摸打先摸后打，后续吃/借可接上一段落点；目标随快照变化时重定向剩余路径，失效目标取消。尊重prefers-reduced-motion。
