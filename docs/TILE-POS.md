# 单字主要词性与起手发牌

应用1.32.0，规则1.8.0，词性配置primary-pos-v1。

每张字牌按单字的主要用法分配一个词性，不预设句子、固定三字组合或整句模板，也不在开局调用大模型。实际组句时仍可使用其他合理词义，胡牌继续按原评审流程决定。

## 词性依据

基础数据为[Jieba v0.42.1词典](https://github.com/fxsjy/jieba/blob/v0.42.1/jieba/dict.txt)的11,580个单汉字词条，原词典SHA256为`7197c3211ddd98962b036cdf40324d1ea2bfaa12bd028e68faa70111a88e12a8`。使用单字词条自己的主要标签；不把含此字的所有词语累计成“概率”，也不把原词库的造句用途分组当作词性。

常见牌字按普通独立用法校正，例如“我／你／您”为代词，“人／花／树／家／钱”为名词，“吃／喝／爱／看”为动词。“能／会／可”为助动词，不单独作为主谓宾中的谓语；“们／垃／圾”等构词语素也不冒充主语或宾语。多义字只选一个发牌分类；这是确定性启发式，不宣称上下文消歧的统计最优解。

- 主语、宾语：各一张名词或代词，实体牌必须不同；相同字有多张时可以分别抽中。
- 谓语：一张动词，不能与主语／宾语共用实体牌。
- 其余词性：形容词、副词、介词、连词、助词、数词、量词、叹词、拟声词、方位词、时间词、助动词、语素及其他。仍可作为其余随机手牌。

当前线上三个套组共358种字已全部标注，见[单字主要词性](../【牌库】/单字主要词性-v1.0-【codex】.json)，配比覆盖见`docs/evidence/pos-opening-1.32.0-current-decks.json`。未被词典收录的自定义生僻字标为“其他”，不凭字形猜作名词或动词；仍能进入随机补牌。后续修改主要标签时须升级配置及规则，不能静默改变同版发牌语义。

## 发牌及边界

先沿原种子洗牌，再从洗好的实体牌墙中抽取各座位的主语、谓语、宾语。对应实体前置到前三轮轮流发牌，其余未选牌保持原洗牌相对次序并随机补齐。庄家仍14张、其他人13张，不增删牌、不改变套组配比、总数或牌权。指定AI与真人待遇相同，不向其他玩家公开手牌或选中实体。

每桌N人至少需要2N张名词／代词及N张动词。两个候选池互斥，因此这个条件足够保证所有座位获得三个不同实体。只满足词性构件不保证三字已经自然成句，更不代表14字胡牌成功率；玩家仍须自行组合其余字牌。

自定义牌组不足时，在归档、升级版本、消耗随机数或创建新牌之前拒绝START，返回`INSUFFICIENT_OPENING_POS`并给出调整配比或更换牌组的提示。可以继续编辑牌组后重新开局；不会添加配给牌、借用别人的牌、死循环重洗或退回纯随机。

活动旧局的手牌、牌墙、种子和期限均保留；只有下一次合法START归档后，1.1—1.7.1升级到1.8.0。1.0兼容局继续原规则。计时沿用真人120秒、AI1.5秒、响应15秒、评审60秒，独立AI评审、十圈借字胡和二十圈改字不变。

## 来源与复现

生成器`scripts/build-tile-pos.py --source <原dict.txt>`校验固定SHA256再导出单字表；常用字校正在`packages/engine/tile-pos.ts`，发牌在`packages/engine/opening-hand.ts`。不新增Python或NLP运行依赖。原Jieba采用MIT许可，许可随网页交付于`/licenses/Jieba-MIT.txt`。
