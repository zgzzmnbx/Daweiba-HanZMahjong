# 3D牌桌接入验收 · V1.1.0

这份清单验收 EnglishMahjong-web 牌桌视觉的真实接入，不改 V1.0.0 游戏规则。它补充 `04-ACCEPTANCE.md`，不能替代其中 S02–S95 的引擎、网络和恢复验收。上游固定基线为 `6830301df3061cdd25350cf56807473e5505b311`；结构迁移说明见 `11-ENGLISH-TABLE-ADOPTION.md`。`contracts/table-view.ts` 是显示契约及少量纯函数，不是游戏实现。

## 1. 证据等级与本包运行范围

运行 `python3 checks/validate-table-ui.py` 只校验本包 UI 数据结构、20种 N/mySeat 的显示映射、左右字锚点修剪、移动网格几何、异议区间形式、动画戳相等模型、示例公共/本人投影、牌池容量预算。它既不调用实际 React/Three 适配器，也不启动浏览器、服务器或显卡。脚本 PASS 只能写作 `PASS_FIXTURE_SCHEMA_AND_DISPLAY_MODELS`。

下面 UI01–UI32 初始全部 `NOT_RUN`，原因是游戏实现尚待完成。真实截图、帧率、GPU资源释放、联机游戏、Mac与云端部署均未执行。将来必须逐项填写真实日期、构建提交、设备/浏览器、输入、截图或录屏、实测结果和剩余缺陷。不得将 JSON 中的 expected 字段当作被测适配器的返回值。

## 2. 数据流与权威边界

1. SocketAdapter 首先接收并按房间/局、公共 stateVersion、本人 controlEpoch 和独立草稿版本处理服务器事件。`RESYNC` 原子替换同一信封中的公共与本人私密快照、serverNow、legalActions；过期事件丢弃。控制权撤销立即关闭旧页面写入口并清除旧私密缓存。
2. `PUBLIC_SNAPSHOT` / `PRIVATE_SNAPSHOT` 可能分开发到。完整牌桌投影要求本人 `basedOnStateVersion === public.stateVersion`；暂不一致时请求合并 RESYNC，保留最后的只读画面并明确“同步中”。可先更新公共只读状态，不能拼出未知版本的手牌或重新启用旧动作。只接受认证本人私密快照。空座释放后的 `seat=null` 显示重新选座，不能伪造一个本人座位。
3. 显示适配器只读取 `PublicRoomSnapshot + 本人的 PrivatePlayerSnapshot`，坐标由 Astra 的通用 SeatTemplate / LayoutProvider 提供。牌山只读取 wallRemaining；对手暗牌只读取 handCount 并画无实体身份的通用牌背。已公开弃牌、评审句和历史句可显示服务器已公开的 tileId/汉字，不因此反推出其余手牌。
4. 先提交新的客户端权威快照、更新DOM/按钮/倒计时，再根据合法的新旧快照差异派生短动画。动画在下一帧前获得新的不可变 `ViewStamp`，含 roomId、roundId、phaseId、publicRevision、controlEpoch、draftVersion、candidateDraftVersion、renderRevision。任意一项变化都使旧动画完成回调失效。私人重排不增加公共版本，所以必须保留独立草稿版本和本地 renderRevision。
5. 动画只改变表现位置/透明度，不移动牌权、不更新服务端状态、不发送 DISCARD/RESPOND/VOTE、不决定计分，也不等待动画完成才开8秒响应窗。迟到、跳版本、恢复、暂停、换局、WebGL丢上下文或减少动态模式，均直接取消旧效果并吸附到最新快照；服务端已合法提交的AI弃牌保留。
6. 倒计时用 `serverNow` 与服务端 deadline 校准。暂停展示 `remainingMsWhenPaused`；不把暂停换成另一种业务 phase。浏览器归零仅提示/同步，不在前端开奖、摸牌、弃牌或结算。legalActions 来自服务器信封，按钮另与连接、控制权、暂停和 pending 门控求交；显示契约不授予动作权限。SAVE_DRAFT 的独立版本规则仍按 S77，不能把动画戳相等检查误用为所有命令的服务端门控。

## 3. 单份排句与文字牌身份

`SentenceRackController` 是本人手牌的唯一输入控制器，`SentenceRack` 与投影DOM层提供可见或无障碍入口。桌面默认采用与3D牌投影对齐的透明DOM命中层，用户可切入清晰的DOM整理模式；进入可见DOM整理模式时隐藏3D本人牌面区域。手机默认可见DOM双行排句。无论采用哪种显示方式，不能同时出现两份可选择手牌、两套草稿状态或两条出牌命令路径。相机、viewport或mesh变化时同步更新DOM投影命中坐标；坐标失配先禁选，不能误选相邻牌。WebGL mesh 永远不进入 Tab/读屏树、不独立 raycast 发命令。只读同步镜像与候选借牌引用均不构成第二份实体牌权。

React key、mesh userData、拖拽状态和选中状态跟随 tileId；同汉字可以共享字符纹理，但不能共享选择身份。候选排句拥有13张真实手牌加1张标注“借用”的引用；原弃牌仍保留服务器 RESERVED 状态。提交前不公开候选排列，结束后清理候选草稿，不把第14张存回普通13张草稿。

390px的横向算式为 `2×17 + 7×44 + 6×8 = 390`；430px为 `2×20 + 7×48 + 6×9 = 430`。13/14字均固定两行，每行至多7张。三枚逗号占预留的左字牌右/下留白或overlay，不新增网格列宽；不得再把3个10px标点塞进已经390px的总宽。第7字后的逗号仍锚在第7字之后，换行不能悄悄变成第8字之前。细窄缝只作可视落点，提供“选逗号→选左字→放在后面”的44px等价按钮和完整键盘路径。

## 5. 性能、资产与回退记录要求

帧率是实现目标，必须先填清设备后测；没有硬件现场则保持 `NOT_RUN_ENV_REQUIRED`。清理验收记录预热基线与20次循环后对象/内存趋势，不设跨设备不可解释的绝对内存数字。资源预算必须至少包含当前人数牌库的所有实体牌、1个拖动ghost和1个借牌引用；引用/ghost与物理牌权分开计数。不能把108上限改成216后继续让额外视图触发静默截断。

字体资源及上游可复用资产应按11文档所列来源和许可处理；保留必要署名。缺字/资源失败触发清楚的DOM回退，不能换回英文字母掩盖问题。截图对照允许参考上游的机位、轮廓、桌面材质区域，同时要求中文与2–6人新布局能读、能点；布局调整不需要追求逐像素相等。
