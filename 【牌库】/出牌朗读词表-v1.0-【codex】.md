# 出牌朗读词表 v1.0

适用于当前两个套组的178种字。每个词恰好两个汉字，首字就是字牌；同字重复牌共用音频。功能字采用固定短语或拟声词，如“们俩”“么么”“啊呀”；多音字按所配词语发音，如“了解”“的确”“着急”“给予”。胡牌不使用本表，仍念权威公开完整句子。
